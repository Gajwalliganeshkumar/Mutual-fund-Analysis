#  Mutual Fund Performance Analysis (EDA Project)

This project focuses on an in-depth Exploratory Data Analysis (EDA) of mutual fund schemes to evaluate their performance using Python and visualization libraries.

##  Project Overview
In this analysis, I worked on a dataset of 814 mutual fund schemes, performing the following key tasks:
-  **Data Cleaning**: Handled missing values, incorrect types, and converted financial ratios to numeric values.
-  **Duplicate Detection**: Verified and removed any duplicate entries.
-  **Outlier Identification**: Used statistical insights and visual tools (boxplots, histograms) to detect outliers in fund size, expense ratios, etc.
- **Visualization**: Created impactful and well-labeled charts using **Matplotlib** and **Seaborn**.
-  **Performance Analysis**:
  - Identified **top & bottom performing mutual funds** by category and sub-category.
  - Analyzed fund metrics like **Sharpe, Alpha, Beta, Sortino**, and **Standard Deviation**.
  - Explored fund performance based on **risk levels**, **rating**, **age**, and **fund managers**.
-  **Investment Suggestions**: Analyzed fund performance trends to guide future investment choices.

##  Tools Used
- Python (Pandas, NumPy)
- Matplotlib
- Seaborn
- Jupyter Notebook

##  Business Questions Answered

###  Performance & Returns
1. Which funds delivered the **highest 5-year returns** by category and sub-category?
2. Which fund managers consistently outperformed across different fund types?
3. Are **high-return funds correlated** with higher risk levels?
4. How do returns vary between **newer vs. older funds**?

###  Expense Ratio & Fund Size
5. Is there a relationship between **fund size and expense ratio**?
6. Which **fund categories or sub-categories** carry the highest administrative cost?
7. Do **low-rated funds** have higher expense ratios?

### ⚖ Risk, Volatility & Ratings
8. Which risk levels are most common among top-performing funds?
9. How do **Sharpe**, **Beta**, **Sortino**, and **SD** vary across categories?
10. Are **0-rated funds** really underperformers, or are they just new?

###  Fund Strategy Insights
11. What investment patterns emerge from **minimum SIP and Lumpsum** requirements?
12. Which **AMC (Asset Management Company)** manages the most schemes or the most highly rated ones?
13. Do **Equity funds consistently outperform** other categories over longer durations?
